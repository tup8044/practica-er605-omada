Práctica de Balanceo de Carga

Guía Interactiva de Laboratorio con TP-Link Omada ER605 Gigabit Multi-WAN Router

🌐 ¿Qué es el Balanceo de Carga?

Es una técnica de administración de red que distribuye el tráfico saliente de la LAN entre múltiples interfaces WAN (proveedores de Internet), previniendo saturaciones de ancho de banda y maximizando el rendimiento.

⚡ Beneficios Clave

Aumenta la velocidad efectiva disponible, garantiza redundancia mediante Failover automático ante caídas de enlace y mejora la estabilidad operativa del entorno corporativo o escolar.

🛠️ Paso a Paso de la Práctica

Selecciona cada pestaña para consultar la configuración requerida:

Paso 1: Habilitar Puerto WAN Secundario

Ingresa a la consola web del ER605 en http://192.168.0.1. Ve a Network > WAN Mode y selecciona 2 WAN Ports para habilitar el puerto WAN/LAN1 como interfaz de Internet adicional.

Figura 1.1: Habilitación de puertos Multi-WAN en la interfaz web de Omada.

Paso 2: Asignación de Direcciones IP

Ve a Network > WAN y selecciona el tipo de conexión (DHCP o IP Estática) para WAN1 y WAN2. Asegúrate de que las subredes de las WAN no colisionen con el segmento de la LAN (192.168.0.X).

Figura 2.1: Asignación de parámetros de red por interfaz WAN.

Paso 3: Monitoreo de Enlaces (Online Detection)

Accede a Network > WAN > Online Detection. Cambia el modo a Manual e introduce direcciones IP públicas de prueba para el rastreo de latencia y disponibilidad por Ping.

Network > WAN > Online Detection Mode: Manual
WAN1 Target Ping IP: 8.8.8.8 (Google DNS)
WAN2 Target Ping IP: 1.1.1.1 (Cloudflare DNS)

Paso 4: Activación del Algoritmo de Balanceo

Ve al menú Transmission > Load Balancing > Basic Settings. Marca la casilla Enable Load Balancing y habilita la distribución proporcional en función del ancho de banda disponible.

Figura 4.1: Activación de políticas de balanceo de carga en la consola.

Paso 5: Pruebas de Tráfico y Failover

Ejecuta el comando tracert 8.8.8.8 desde una máquina cliente en la LAN para verificar el salto por la WAN primaria. Desconecta físicamente el cable de WAN1 para confirmar la conmutación automática inmediata a la línea WAN2.
